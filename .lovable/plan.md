## โครงสร้างที่จะสร้าง

### Package 1: `งานบุญครบวงจร Standard (พิธีสงฆ์อย่างเดียว)`
- 1 tier เดียว ราคา **12,000 ฿**
- description: "จัดงานบุญทั้งหมด ยกเว้นอาหาร เหมาะกับเจ้าภาพที่จัดอาหารเอง"
- custom_attributes: ระบุชัดว่ามีอะไร (พิธีสงฆ์, นิมนต์พระ, อุปกรณ์) แต่ **ไม่มีอาหารใดๆ**
- min_condition: "พิธีสงฆ์อย่างเดียว ไม่รวมอาหาร"

## งานที่จะทำ

### 1. Insert ข้อมูล 2 แพ็กเกจ ลง `catering_packages`
ผ่าน insert tool — ใช้ category `บุญ+บุฟเฟ่ต์` ที่มีอยู่แล้ว

### 2. ปรับ edge function เล็กน้อย (`supabase/functions/line-webhook/index.ts`)
เพิ่มกฎใน "💰 กฎการตอบราคา":
- "บางแพ็กเกจมีตัวเลือกพิเศษระบุใน notes/ai_instruction (เช่น 'อิ่มบุญ' = ไม่รวมอาหารแขก) — ต้องเสนอเมื่อตรง use case"

### 3. ไม่แก้ฟอร์ม / ไม่แก้ schema
ฟอร์มและ schema ปัจจุบันรองรับครบแล้ว
