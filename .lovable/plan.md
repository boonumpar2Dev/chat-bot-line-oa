# แผน: เพิ่มกฎสอน AI 2 ข้อใหม่

## ปัญหาที่พบจาก screenshot
1. AI **มั่วสถานที่** — ลูกค้าไม่ได้บอก แต่ AI สรุปเองว่า "เรือจอดอ่าวอุดม ชลบุรี กลางทะเล" (ไม่อยู่ใน KB ไม่ใช่ข้อมูลที่ลูกค้าให้)
2. หลังลูกค้าให้เบอร์แล้ว AI ยัง **ยัดข้อมูลเพิ่ม + ถามต่อ** ทำให้บทสนทนาไม่จบ ทั้งที่ควรปิดบทสนทนาแล้วรอเจ้าหน้าที่

## แนวทาง (ไม่แก้ code)
เพิ่ม 2 กฎเข้า `app_settings.strict_rules` (array ของ string) — ฟิลด์นี้ถูกต่อท้าย system prompt ของ AI อยู่แล้วทั้งใน `kb-chat-test` และ `line-webhook` และแอดมินแก้ได้เองจากหน้า **Settings → การทำงานของ AI**

## กฎที่จะเพิ่ม

**กฎที่ 1 — ห้ามเดาข้อมูล:**
> ห้ามเดา/แต่งข้อมูลที่ลูกค้าไม่ได้บอกและไม่อยู่ใน KB เด็ดขาด โดยเฉพาะ **สถานที่จัดงาน** (เช่น ชื่อจังหวัด, สถานที่เฉพาะ, "กลางทะเล", "บนเรือ") — ถ้าลูกค้ายังไม่ระบุ ให้ถามตรงๆ ห้ามสมมติเอง และห้ามเอาคำในชื่อแพ็กเกจ/KB มาตีความเป็นสถานที่ของลูกค้า

**กฎที่ 2 — เมื่อได้เบอร์แล้วให้ปิดบทสนทนา:**
> เมื่อลูกค้าให้เบอร์โทรแล้ว ให้ตอบสั้นๆ ยืนยันรับเบอร์ + แจ้งว่าเจ้าหน้าที่จะติดต่อกลับ **ห้ามยัดข้อมูลแพ็กเกจ/รายละเอียดเพิ่มเอง และห้ามถามคำถามต่อ** ถ้าลูกค้ามีคำถามเพิ่มค่อยตอบเป็นรายข้อ (ไม่งั้นบทสนทนาจะไม่จบ)

## วิธีทำ
- Migration: `UPDATE app_settings SET strict_rules = strict_rules || <2 กฎใหม่> WHERE key='ai_config'`
- ไม่แตะไฟล์ edge function ใดๆ
- ไม่แตะ UI Settings (มีช่องแก้ strict_rules อยู่แล้ว แอดมินจะเห็น 2 บรรทัดนี้และแก้/ลบได้เอง)

## ทดสอบหลัง implement
1. เคส "สนใจจัดงานทำบุญ 45 ท่าน 28 พ.ค." (ไม่บอกสถานที่) → AI ต้อง**ถามสถานที่** ไม่ใช่เดาว่าเรือ/อ่าวอุดม
2. เคสลูกค้าให้เบอร์ `0851654447` → AI ต้องตอบสั้นยืนยัน + จบ ไม่ยัดข้อมูลแพ็กเกจ
