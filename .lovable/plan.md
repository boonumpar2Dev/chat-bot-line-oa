# แผนงาน 5 เรื่อง (เรียงตามลำดับทำ)

## 1) ค่าเดินทาง (โต๊ะจีน) + ชิมฟรี — เพิ่มเป็น KB

เพิ่ม 2 KB entries ใหม่ในตาราง `knowledge_base` (category = "เงื่อนไขบริการ"):

**Entry A — ค่าเดินทาง**
- Title: `ค่าเดินทาง / ค่าจัดส่ง`
- Content:
  - งานบุญ + โต๊ะจีน ในเขตกรุงเทพ-ปริมณฑล: **ไม่มีค่าเดินทาง**
  - **ต่างจังหวัด: เริ่มต้น 1,500 บาท** แอดมินประเมินตามระยะทางและแจ้งภายหลัง
  - บุฟเฟ่ต์ / ซุ้มอาหาร: ไม่มีค่าเดินทาง

**Entry B — ชิมฟรี**
- Title: `ชิมอาหารฟรี ที่บริษัท`
- Content: ลูกค้าสามารถนัดมาชิมฟรีที่บริษัทได้ก่อนตัดสินใจ (ระบุเงื่อนไข/วันเวลานัด ให้ user แก้ทีหลัง)

เสริม system prompt ใน `line-webhook` + `kb-chat-test`: เพิ่มกฎสั้น ๆ ให้ดึง KB หมวด "เงื่อนไขบริการ" มาตอบเมื่อลูกค้าถาม "ค่าเดินทาง / ค่าส่ง / มาชิมได้ไหม / ชิมฟรี"

## 2) จัดลำดับฟอร์มสอน AI + บล็อกตัวอย่าง

ปรับ `src/pages/Knowledge.tsx` ให้แท็บเรียงตามลำดับใหม่:

```text
[ข้อมูลทั่วไป (KB)] → [ประเภท (Categories)] → [แพ็กเกจ/สินค้า] → [โปรโมชั่น]
```

**บล็อกตัวอย่างแก้ไขได้** — ในฟอร์ม Add/Edit ของทุกแท็บ เพิ่มปุ่ม "📋 ใช้เทมเพลตตัวอย่าง" ที่ prefill ข้อความตัวอย่างพร้อมคำแนะนำในช่อง (description / ai_instruction / content) ให้ user แก้ตามได้เลย แทนการเริ่มจากช่องว่าง เทมเพลตเก็บเป็น constant ในไฟล์ (ไม่ต้องเพิ่ม DB)

```
ชื่อแพ็ก: ____
เหมาะสำหรับ: งานบุญ X รูป + แขก Y ท่าน
ราคา/ท่าน: ____ บาท
รวม: เมน
